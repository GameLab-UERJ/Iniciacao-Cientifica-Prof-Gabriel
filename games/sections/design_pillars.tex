\section{\textit{Design Pillars}: O que é central para a experiência}

Utilizamos \textit{Design Pillars} para orientar nossas 
escolhas de design à medida que avançamos no projeto. 
Para os propósitos deste projeto, queremos que nossos 
\textit{Design Pillars} identifiquem os tipos de diversão 
ou entretenimento que são fundamentais para a experiência 
do usuário.
