kim2020.pdf
Resume:

The study proposes a fighting game AI trained through deep reinforcement learning, combining self-play with Monte Carlo Tree Search (MCTS) to improve performance in the FightingICE environment. The authors investigate reinforcement learning configurations, including state representation, reward shaping, and opponent selection, to optimize training. Results demonstrate that integrating delayed and simulated state information, comprehensive rewards, and a 1:3 MCTS-to-self-play training ratio produces the strongest agent, achieving a 94.4% win rate against top competition bots. The authors conclude that this approach enables the agent to earn effective game strategies and provides a strong baseline for future fighting game AI research.

zeng2022.pdf
Resume:
ChatGPT prompt:

The study proposes a Dynamic Difficulty Adjustment (DDA) framework for multiplayer Minecraft servers that adapts enemy (mob) difficulty to accommodate players with varying skill levels. Unlike traditional DDA designed for single-player games, the framework adjusts shared enemies based on the collective abilities of nearby players, aiming to create balanced and enjoyable cooperative gameplay. A prototype was implemented and evaluated through a user study involving 23 participants. Results showed that the system increased perceived challenge while maintaining high enjoyment, suggesting improved skill–challenge balance. The authors conclude that the framework is a practical foundation for multiplayer DDA and can be extended and refined for broader multiplayer game applications.

Personalized dynamic difficulty adjustment imitation learning meets reinforcement learning

File name:

Resume:
ChatGPT prompt:
Summarize the following text using the abstract and conclusion in 100 words.
The study proposes a personalized dynamic difficulty adjustment (PDDA) framework that combines imitation learning and reinforcement learning to create AI opponents that adapt to individual player behavior in real time. An imitation learning agent models the player’s actions, while a reinforcement learning agent is trained to outperform this model, producing personalized and evolving challenges. Preliminary evaluation in the FightingICE environment showed higher player satisfaction compared with a standard Monte Carlo Tree Search (MCTS) opponent. The authors conclude that the framework enables personalized gameplay with minimal designer effort and has strong potential for further refinement through larger user studies and more advanced imitation models.

Go with the flow: Reinforcement learning in turn-based battle video games
Link:

File name:
pagalyte2020.pdf
Resume:
ChatGPT prompt:
Summarize the following text using the abstract and conclusion in 100 words.
The study proposes a reinforcement learning (RL)-based Dynamic Difficulty Adjustment (DDA) approach to maintain player flow in turn-based battle games. Using a SARSA algorithm, the AI opponent adapts its action selection according to the player’s performance rather than modifying game statistics or the environment. Rewards are dynamically adjusted based on consecutive player wins or losses, creating personalized challenges. Evaluation results indicate that the RL agent learns effective battle strategies over time, with a 30:70 exploration-to-exploitation ratio achieving the best balance. The authors conclude that RL-driven opponents can improve game flow and provide a foundation for more adaptive AI in complex turn-based games.
